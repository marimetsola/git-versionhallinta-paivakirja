# Oppimispäiväkirja: Paikallinen git

**Mikä osion tehtävissä oli vaikeaa ja mikä helppoa? Mikä auttoi minua oppimaan? Miten selvitin esteet?**

Olen käyttänyt Gitiä ja GitHubia aika paljonkin, mutta vain perus pull, push, merge komennoilla. Varsinaisesti tässä ei siis ollut mitään vaikeaa. Alun ohjeistus oli hieman sekava, koska en tajunnut mitä tarkoittaa "vie". En ollut täysin varma pitääkö committaa ja milloin. Homma selvisi lukemalla ohje tarkemmin ja kysymällä tekoälyltä miten se tulkitsee ohjeistuksen.🙈

## Osiossa käyttämäni Git-komennot

| Komento  | Kuvaus                                          |
| -------- | ----------------------------------------------- |
| add      | Lisää tiedoston/muutokset staging area:lle      |
| reset    | Poistaa tiedoston/muutokset staging area:lta    |
| restore  | Palauttaa tiedoston viimeisimpään tallennettuun |
| commit   | Tallentaa muutokset                             |
| status   | Näyttää muutosten tilan                         |
| log      | Listaa commit historian                         |
| rm       | Poistaa tiedoston levyltä ja versionhallinnasta |
| tag      | Lisää committiin tagin                          |
| checkout | Vaihtaa branchia                                |
| switch   | Vaihtaa branchia                                |
| revert   | Peruuttaa commitin                              |
