# Oppimispäiväkirja: Hajautettu git

**Mikä osion tehtävissä oli vaikeaa ja mikä helppoa? Mikä auttoi minua oppimaan? Miten selvitin esteet, jotka vaikuttivat tehtävän suorittamiseen?**

En kohdannut haasteita. Olen kloonannut repoja ja luonut omia. Fetchin ja pullin ero selkiytyi kuten myös se, että origin on vain määritelty nimi.

## Osiossa käyttämäni Git-komennot

| Komento       | Kuvaus                                                                        |
| ------------- | ----------------------------------------------------------------------------- |
| clone         | Kloonaa muualla olevan repon omalle koneelle                                  |
| fetch         | Hakee muualla olevan repon omalle koneelle omaksi branchikseen                |
| pull          | Hakee muualla olevan repon omalle koneelle omaksi branchikseen ja mergeää sen |
| remote add    | Lisää repolle remoten                                                         |
| remote rename | Uudelleennimeää viittauksen etärepoon                                         |
| merge         | Yhdistää kaksi branchia                                                       |
| push          | Työntää local muutokset etärepoon                                             |
